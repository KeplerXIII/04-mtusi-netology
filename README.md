## 📊 Результаты оценки моделей и расчёт стоимости

Отчёт по результатам проведения `eval_test` расположен в каталоге:
[`eval_results`](./eval_results/).

В рамках тестирования были проанализированы показатели:

* точность ответов (accuracy),
* время до первого токена (TTFT),
* скорость генерации (throughput).

---

## 💰 Оценка стоимости

Расчёт стоимости выполнен с использованием учебного калькулятора в разрезе предполагаемых прикладных сценариев системы:

* сбор и первичная обработка материалов (web scraping),
* генерация отчётов и дайджестов,
* работа с RAG по накопленным данным,
* работа с локальными нормативными актами (ЛНА).

Следует отметить, что расчёты носят оценочный характер, поскольку:

* фактические объёмы запросов и токенов могут отличаться,
* конкретная модель для промышленного использования не зафиксирована,
* стоимость API может варьироваться в зависимости от провайдера и условий использования.

---

## 🧠 Выбор модели

По результатам `eval_test` наилучшие показатели продемонстрировала бесплатная модель, используемая через OpenRouter.

С учётом полученных метрик, а также отсутствия затрат на использование API, её применение представляется наиболее целесообразным на текущем этапе.

Дополнительным преимуществом является отсутствие нагрузки на собственную инфраструктуру, в отличие от локальных моделей, требующих вычислительных ресурсов (GPU/CPU) и сопровождения.

Таким образом, на данном этапе рекомендуется использование бесплатной облачной модели с возможностью последующего пересмотра выбора при изменении требований к качеству, скорости или стоимости решения. (Если она конечно завтра не закроктся =)


## 🚀 Запуск проекта

Проект использует `pyproject.toml` для управления зависимостями.
Команда `uv sync` устанавливает все необходимые пакеты автоматически.

---

### 1. Установка зависимостей

```bash
uv venv
uv sync
```

---

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
OPENROUTER_API_KEY=your_api_key_here
```

---

### 3. Запуск Ollama

```bash
ollama serve
```

Скачайте модели:

```bash
ollama pull gemma4:e4b
ollama pull qwen3:14b
```

---

### 4. Запуск бенчмарка

```bash
uv run python -m eval.runner
```

---

### 5. Расчёт стоимости

```bash
uv run python -m eval.cost_scenarios
```
